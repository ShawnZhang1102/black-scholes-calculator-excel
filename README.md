# Black-Scholes Option Calculator (Excel)

> Class Project · University of Rochester

A Black-Scholes option pricing calculator in Excel, with call and put values side by side on a single sheet.

## What It Does

Prices European call and put options from five inputs:

- Current price of the underlying
- Exercise (strike) price
- Risk-free interest rate
- Time to expiry (in years)
- Volatility

Change any input and both the call and put values update immediately.

## Tech Stack

Excel · Black-Scholes model · NORM.DIST

## How to Run

Download `Black-Scholes-Calculator.xlsx` and open it in Excel. (GitHub cannot preview Excel files — download the file to view it.)
